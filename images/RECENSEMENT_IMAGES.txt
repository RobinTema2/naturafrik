INSTRUCTIONS POUR REMPLACER UNE IMAGE
------------------------------------------------------------

OPTION A — Même extension (recommandé, aucune modification de code) :
  → Supprimez l'ancien fichier SVG
  → Copiez votre image dans le dossier images/
  → Renommez-la exactement comme l'ancien fichier
  → Exemple : votre photo de cacao → renommez-la "cacao-beans.svg"
     (même si c'est un JPG, le navigateur acceptera)

OPTION B — Extension différente (ex: .svg → .png) :
  → Copiez votre image dans le dossier images/
  → Renommez-la avec la bonne extension
  → Exemple : natcacao.png
  → Prévenez le développeur pour qu'il mette à jour
     les références dans le code source

------------------------------------------------------------
FORMATS RECOMMANDES
------------------------------------------------------------

  JPG   : Photos, paysages, produits en situation
  PNG   : Images avec fond transparent (sachet, logo, emballage)
  WebP  : Meilleure option — plus léger que JPG/PNG, même qualité
  SVG   : Uniquement pour les icônes et logos vectoriels
